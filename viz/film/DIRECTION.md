# Film direction — "Star-atlas plate, in motion"

One committed direction (per the anti-AI-slop rule: decide once, stay consistent).

**The line:** the library is a printed astronomical *plate* that assembles itself — 8,000
songs as fine luminous marks on ink-dark paper, sorted into genre constellations by a model
that was never told the genres, then read like a record-shop poster (Archivo-Black slugs,
mono datelines) pressed onto a night sky.

**Materials**
- Ground: warm ink `#0a0b0f` plate (not pure black), faint vignette + procedural film grain,
  a hairline printed plate border with a mono credit line — editorial, not HUD.
- Marks: 1.5–3px additive points in **muted risograph spot inks** (NOT neon, NOT rainbow).
  One spot ink per genre, ~10 max. No purple/violet (banned tell).
- Type: **Archivo Black** for kinetic slugs (embedded woff2); system mono for datelines/labels.
  No Inter / Space Grotesk / Chakra Petch.
- Accents: International Klein Blue `#3d5bff` (query beam / active), signal red `#e0301e`
  (now-playing marker, autoplay comet head). Everything else stays quiet so these read.
- Motion: eased & physical — particle-to-position morph (distance-staggered), virtual camera
  dolly/zoom, mask/clip kinetic type. Luminosity from additive marks + restraint, NOT glow
  loops. Grain/vignette is the "plate" texture — no scanlines, chamfers, glassmorphism, HUD ticks.

**Avoids every named tell:** neon-on-black, purple gradients, glow/glass, scanlines/chamfers/
HUD microcopy, techy fonts, Spotify dashboard shell, scroll-reveal-as-only-idea.
